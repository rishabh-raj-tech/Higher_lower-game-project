# Higher Lower Game

A simple, interactive command-line Python implementation of the classic **Higher or Lower** guessing game. Test your intuition by comparing two random choices and guessing which one has more Instagram followers (or search volume, population, etc.)!

---

## Features

* **Dynamic Data Comparison:** Randomly pairs two subjects from a data set for each round.
* **Score Tracking:** Keeps track of your current streak as you guess correctly.
* **Game Over Handling:** Instantly reveals your final score upon an incorrect guess.
* **Seamless Transitions:** Automatically moves the correct answer to the next round as the new baseline (Position A).
* **Console Clearing:** Clears the terminal between guesses for a clean visual UI.

---

## Prerequisites

* **Python 3.x** installed on your system.
